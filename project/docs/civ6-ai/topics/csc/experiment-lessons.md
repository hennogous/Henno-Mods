# Experiment interpretation and operational lessons

The largest gains in confidence came from narrowing questions and preserving negative evidence. This page records interpretation rules; native architecture and controller implementation have separate reference pages.

## AI-C042 — Controls must share the getter and context

Loaded rows and empty modifier subject lists do not establish delivery. UI/Gameplay getters can disagree, initialization phases differ and saved instances may retain earlier behavior. A responsive same-path positive control must precede interpreting a zero.

Scope: Farm, acquisition, producer-property and general mechanism probes.

Limits: Failed positive controls make route interpretation inconclusive. They do not prove a mechanism unsupported everywhere or justify arbitrary coefficient increases; isolate application before testing decisions.

Sources: [Delivery](../../../research/mods/csc-ai-acquisition-signal-delivery-20261024.md), [mechanism results](../../../research/mods/csc-ai-mechanism-tests-20261025-results.md), [producer calibration](../../../research/mods/csc-ai-producer-property-calibration-20261029.md).

## AI-C043 — Worlds, clocks and source generations must match

Same seeds do not guarantee identical resources/starts across builds. Saved-world arms overlap; Medieval starts 71 and Online/Standard clocks differ. Preserve initial state, actual boundaries, exact executed packages and accepted log generations.

Scope: Baseline, research, material, producer and planner comparisons.

Limits: Never sum replays as independent outcomes, fill missing telemetry, compare historical pins against promoted source, or describe a post-closure repair as runtime validation. Cached advice, proposals and decisions have separate refresh timing.

Sources: [Benchmark contract](../../../research/mods/csc-ai-benchmark-metrics-20261022.md), [Farm recovery](../../../research/mods/csc-ai-resource-farm150-test-20261024.md), [v2 recovery/result](../../../research/mods/csc-ai-customer-aware-planner-v2-native-20261101.md).

## AI-C044 — Stall, save failure, host loss and native crash differ

Disaster/diplomacy playback locks produced verified stalls; shipped UI release sometimes restored progress. Host shutdowns and optional-save failures preserved useful partial data without proving native crashes. One shared finite controller, identity-qualified owners and one-shot financial receipts improved reliability.

Scope: Foundation-series recovery, harness and shared-session/exit investigations.

Limits: A missing reply or vanished worker is not a cause diagnosis. Acknowledgment is not completed effect; ambiguous economy must not be resent. Repair reporting offline rather than rerunning worlds for missing fields.

Sources: [Foundation-series history](../../../research/mods/csc-ai-dynamic-foundations-three-games-20261021.md), [harness performance](../../../research/mods/csc-ai-harness-performance-20261023.md), [exit investigation](../../../research/mods/csc-ui-exit-crash-20261031.md), [shared session](../../../research/mods/csc-shared-native-session-20261030.md).

## AI-C045 — Instrumentation cost can defeat the question

Two placement diagnostics produced 882774 and 294437 callbacks in one AI interval, captured no target Quarter decision and closed normally. Moving hooks did not solve fan-out; no weight treatment followed. Native-side filtering before the JavaScript boundary became the prerequisite for future instrumented captures.

Scope: Bounded November 1 observer branch, current Windows build.

Limits: This is a measurement-budget failure, not AI blindness, a successful calibration or permission for a third retry. The broad optimisation campaign remains paused.

Sources: [Control evidence](../../../research/mods/csc-native-quarter-placement-control-evidence-20261101.md), [full investigation](../../../research/mods/csc-native-quarter-placement-weights-20261101.md).

## AI-C046 — Reverse engineering should resolve dependencies

PE checks, reference names, Ghidra and REA clarified consumers, ownership and side effects. Economic goal feasibility stopped at an unestablished arbitrary payload/ownership interface; planner work could continue through supported guidance and guarded acquisition/foundations.

Scope: Native tooling and economic-job feasibility work.

Limits: Names and historical layouts are leads. A scripted operation setter can mutate AI knowledge before invalid-ID validation, so invalid ID is not a safe no-effect control. No universal executor, complete reconstruction or token-savings gain was established.

Sources: [REA trial](../../../research/mods/csc-ai-rea-trial-20261030.md), [symbol resource](../../../research/mods/csc-ai-gamecore-symbol-resource-20261029.md), [economic feasibility](../../../research/mods/csc-ai-native-material-job-feasibility-20261030.md), [roadmap decision](../../../research/mods/csc-ai-native-goal-roadmap-review-20261030.md).

## AI-C047 — The full objective remains unproved

Useful acquisition, fresh value delivery, native selections, repairs, completions and individual functioning chains are demonstrated. Reliable sustained operation, balanced opportunity cost and net benefit across Basic/RH and multiple maps remain open.

Scope: Latest audited project checkpoint plus November 3 source/native work.

Limits: Old diaries may say ACTIVE or pending. Latest human stops, audit closures and paused campaigns prevail. These pages are knowledge, not active jobs, release qualification or authority to start a game/monitor.
