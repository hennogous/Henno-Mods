# Problems 1 and 2: completion contract

Agreed with Henno on 11 November 2026. The active goal closes each numbered
sub-problem at levels 1–3 below, using representative controlled cases.
Additional seeds, configurations and edge cases belong to level 4.

1. **Mechanism:** native code receives and consumes the intervention.
2. **Decision effect:** a controlled comparison changes the relevant native
   choice or action. A score write alone does not close a placement problem.
3. **Integrated:** reusable main CSC code reproduces the effect dynamically
   from live facts, without fixed test-city policy or an external score writer.
4. **Broader qualification:** further coverage, reliability and calibration.

Preserve outcomes explicitly required by the problem. Acquiring a footprint
needs native payment and correct-city ownership; construction follow-through
needs completion. Astra reviews each closure claim. Record the demonstrated
scope permanently; later qualification does not erase it unless contradictory
evidence invalidates the original claim.

each required contribution and outcome. Do not invent separate games merely
to duplicate an already proved consumer or completion path.
