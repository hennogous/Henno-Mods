## Mechanism and scope

[The preceding strategy experiment](csc-ai-granary-priority-20261031.md) found
Following without delivered ordinary Buildings preference. Exact324c static
analysis located the direct leader/civilization-trait path into CityPlanner's
vector and its rebuild on save load. This arm validated that path in-game.
AiLists.LeaderType is a **trait binding**, not a raw leader name.

The three additive rows bind CSC_AI_GranaryDirectPriority_V1 to
TRAIT_LEADER_GENGHIS_KHAN_ABILITY, Granary Favored1/Value0. No strategy, callback,
candidate Game property, real yield, research, production order or building grant
was added. Existing local private40 and RH rows were unchanged. Native roster
preflight proved only original AI3/Genghis/Mongolia shares the trait here; the
human observer does not. This remains persistent trait-wide type bias across
all eleven AI3 cities, not a conditional gap signal or arbitrary player-local
control. General human/autoplay and multi-profile behavior is not established.

Preserved pretrial DB review finds fourteen authored Granary Buildings entries,
but none directly matches Genghis's eleven resolved leader/civilization traits.
That explains the measured baseline0 without needing preference cancellation.
It is not a global statement about other strategy consumers or Wonder logic.

## Decision and next screen

Astra classifies this as **mechanically validated, experimental**. Do not keep
raising weights or try to make the chosen city obey. Integrate the supported
control into one small early-game paired RH screen, common source1→150:

- Direct Genghis trait preference plus unchanged local producer/customer signals.
- Opt-in selective investment guard, credible Base, protected footprints and
  one active assisted chain per original AI; existing guarded backend unchanged.
- Ordinary native construction/material behavior; no Builder or production boosts.
- All-chain material/producer/customer/real-return observations, assistance and
  unfinished costs, non-CSC Granary work, military/economic displacement.

Require absolute worthwhile-chain outcomes alongside per-investment efficiency;
fewer starts or less subsidy alone is not success. Periodic observations are
interval-censored. A promising RH screen earns a matched Basic screen and later
longer/multiple-map validation. A poor one sends work to the first repeated
cross-chain failure. Strategic Service matching remains deferred.
