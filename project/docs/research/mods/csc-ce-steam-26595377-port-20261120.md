## Verified native coordinates

The new GameCore has timestamp `1794358453` and mapped size `12976128`.
Code changed. The audit matched instruction sequences for the declared CE
targets with relative operands masked, resolved ambiguous Lua wrappers
through their class and method strings, and used native references for data
slots. Eight direct call relationships were checked against both images.
The dev build used 164 address declarations, of which 131 moved.

REA with Ghidra independently decoded the new district aggregation,
building nomination, Builder recruitment and worker-tree calls. The guards
retain their original byte lengths with the new exact prefixes. The CE
profile accepts one executable and GameCore pair and keeps native
forwarding on an unsupported pair. The previous CE package remains
available for its historical evidence.

The MSVC Release x64 build passed 264 district-score checks, four hook-group
checks, and the instruction-delivery and restoration test.

A fresh Fractal smoke game reached Online turn 25 through the shared
controller with all placement capabilities ready. The material status
reported technology, civic, Builder, and finishing-only worker support.
CSC still had an enabled district packet at version 25 and zero district
faults. The controller archived the turn-25 observation, closed Civ VI
with exit code 0, and verified preference restoration.

The retained Kish checkpoint matched in both arms. With the finishing
switch enabled, CE advanced the Builder already assigned to repair Flax
plot 2188 on turn 166. The next publication read one native
`workerFinish` receipt. The supplier was working at turn 170. The matched
control still had the pillaged improvement at turn 170. Both arms closed
cleanly and restored preferences.

The scheduler delivered two native finish updates for the same assigned
Builder and Barley Farm at plot 1121, on turns 117 and 119. Both tuned
variants repaired that Farm on turn 119 and the buyer regained working
supply at the turn-120 census. The complete supplier work histories,

the tuned variants. Keep the finishing-only option for demonstrated
recovery cases such as Kish. Continents supplies two accepted offers
and shows the same observed outcomes with the option enabled.

The whole CSC Lua publication averaged 2,027 ms per turn with scheduling
off and 2,059 ms with it on, a measured difference of 32 ms per turn
(1.6%). The maxima were 4,080 and 4,374 ms. These wall times include the
rest of the guidance pass. This is the first full three-way comparison on
the updated build. Pangaea is deferred.
