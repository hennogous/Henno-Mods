## Policy revision selected for implementation

Astra recommends an explicit **district-site decline** for proven absence of
a credible Base path, rather than increasing a numeric penalty until this
fixture passes. CE's existing `SupplierRowMask` is the nearest lifecycle
pattern, but it masks entire owned rows and cannot be reused as the same API.
A new generic `(player, city, district, plot)` scope should temporarily mask
only that cell during the ordinary joint selector, then restore its exact value
before other cache readers and district preparation. No new native address or
raw hook installation is needed. Use bounded versioned staging and exact
receipts; the API is **proposed, not implemented** at this checkpoint.

The native selector can accept zero or negative scores above its floor.
Therefore a low positive ceiling or a mask restricted to positive values does
not express decline. Use its existing floor only during selection, leaving
preexisting floor/below-floor values alone and restoring every changed byte.
This is choice admission, not an estimated economic value or a persistent
invalidity write. Retained plans and all other district cells remain intact.
Reserved cells must also be covered: native selection can exceed reservation
priority. Do not copy the old late-entry resolver's unreserved-only restriction.
Leave reservation handles and retained trees unchanged; add no cancellation or
replacement command.

Main CSC should request this only after proving no adjacent revealed owned or
unowned Base path exists and all mapped Base types are visible. Any unknown
neighbor, possible supplier, incomplete coverage or unknown feasibility must
prevent that conclusion. Do not generalize the initial rule to below4 adjacency
or missing customer access. The scope withdraws automatically when live facts
improve. Missing optional CE support retains the existing finite guidance.

The acceptance remains unchanged: same common knowledge fixture and main policy,
control omitting only the new target decline scopes, actual different native
winner/request, then a credible new Base opportunity with scope withdrawal and
a fresh Quarter choice/request. Ordinary competition with units and other
investments remains native. No stronger numeric band is justified merely to
make the observed306,049 comparison pass.
