The registration of a System and the adoption of a strategy do not prove that
strategy dispatch supports that System. The missing direct dispatch plus scoped
subscription review is a strong explanation of the observed Following→neutral
result. No SQL spelling/join defect was identified. No runtime dispatcher hook
or exhaustive signal-subscriber census was performed.

The direct trait path has a statically supported rebuild-on-load route, so the
existing source110 can test a changed direct input without inventing a stale-save
explanation or generating another world. Native positive readback is still
required. Automatically mapped function names and generic-template aliases are
labels; the pointer offsets, call operands and current-build bodies carry the
argument.
