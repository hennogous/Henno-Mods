# Retired CSC AI tuning — 3 November 2026

Henno requested a fresh start for AI tuning after the native district-score
bridge demonstration. This archive preserves the actual working files at that
point, including uncommitted changes. It is not a reconstruction from Git HEAD.

- `retired/`: the17 runtime/localization files removed from their active paths.
- `before/`: verified byte copies of those files, the original metadata and335
  historical tooling/reference files. `manifest.json` records hashes and operations.
- The historical tooling remains at its original paths for archived research
  imports; it is reference material, not the implementation of the new evaluator.

All15 legacy AI actions, their three criteria, two assistance/subsidy options and
four option labels were removed from active source wiring. The small yield-filter
utility remains because existing Quarter lenses and Wonder tooltips include it;
its compatibility import supplies no AI tuning or private-yield definition.

Quarter gameplay, ordinary compatibility, bundled adjacencies, resource-map
assistance, the shared controller, native bridge and research evidence are retained.
The new experiment lives in `project/tools/native_ai/quarter_placement_trial/` and
imports no legacy site evaluator, subsidy policy or scripted foundation planner.

The matching installed reset changed only three metadata/settings files, with
verified backups. No art or gameplay SQL was rebuilt or replaced. Saved history
is not rolled back by retiring the tuning.

Guarded source restoration is available through
`project/tools/native_ai/archive_legacy_tuning.py --restore`. It refuses to
overwrite later edits. Installed restoration has its separate recorded backup
and `clean_installed_ai.py` procedure. Do not restore these merely to run a new
experiment.
