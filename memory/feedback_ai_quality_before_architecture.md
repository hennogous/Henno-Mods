# AI quality and performance take priority over architectural neatness

Henno,13 November2026: highest-quality gameplay output matters more than the
cleanest architecture, provided performance does not suffer. The central model
remains useful for consistent economics; it is not a reason to reject a working
native SQL route, additional consumer adapter or pragmatic scoped intervention.

cost. Keep bounds/comments/maintainability clear without making elegance an
